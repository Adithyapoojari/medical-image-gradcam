Medical Image Analysis and Grad-CAM Visualization

A Python-based medical image analysis prototype exploring deep learning and visual explainability using Grad-CAM.

Features

- Chest X-ray pathology prediction workflow using TorchXRayVision.
- Skin lesion and brain MRI classification model prototypes.
- Grad-CAM heatmaps for visualizing regions influencing model outputs.
- Image preprocessing and visualization using OpenCV and Matplotlib.

Technologies

Python, PyTorch, Torchvision, TorchXRayVision, OpenCV, NumPy, Matplotlib.

Setup

Install the required dependencies:

pip install torch torchvision opencv-python numpy matplotlib pillow torchxrayvision

Execution

Run the Python script:

python "Image Analysis and visualisation using Deep Learning.py"

Select a model domain and choose an input image when prompted.

Disclaimer

This project is an experimental prototype for educational purposes and is not intended for clinical diagnosis. The skin lesion and brain tumor classification models require appropriate training and validation before their predictions can be considered meaningful.
